# NoCreo 297 — Luxury Storefront V2

This updated version is a standalone responsive website built with HTML, CSS and vanilla JavaScript.

## What changed
- Removed the older website product/logo imagery.
- Added the new NoCreo 297 campaign photos only.
- Added a longer luxury scroll experience with editorial sections.
- Added a campaign gallery with full-screen image viewing.
- Added scroll reveal animation, a stronger hero section, brand story, brand codes, detail section, manifesto, product section and FAQ.
- Kept the product price at €38.50.
- Shipping copy is set to the Netherlands.
- Cart quantity and bag drawer still work.

## Files
- index.html
- styles.css
- script.js
- assets/brand-logo.png
- assets/product-hero.png
- assets/campaign-01.png through campaign-06.png

## Publish
Upload the contents of this folder to your website root (for Hostinger, usually public_html) and replace the old files.

## Important
The checkout button is not connected to a payment processor yet. Connect it to your existing checkout/payment provider before publishing.
